  1. The first time, in Calendar, choose File, then New Calendar, and name it Simply Sub.

On an iPhone or iPad

  1. The first time, in Calendar, tap Calendars, then Add Calendar, and name it Simply Sub.
  2. Open the file from Downloads in the Files app.
  3. Add its events to Calendar, choosing Simply Sub when it asks which calendar.

  4. Select Import from ICS, then choose the file and the Simply Sub calendar.
