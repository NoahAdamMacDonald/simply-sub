Frequently asked questions about Ollama’s cloud models, accounts, authentication, privacy, and requests.
Copy pageCopy page
For questions about installation, hardware, and the local Ollama server, see the local FAQ.
Does Ollama send my prompts and answers back to ollama.com?
Ollama operates with a zero data retention (ZDR) policy.
When you use cloud models, Ollama processes your prompts and responses transiently to provide the service but does not store or log that content and never trains on it. Ollama collects basic account information and limited usage metadata that does not include prompt or response content. Ollama does not sell your data, and you can delete your account at any time.
What is the difference between an API key and my Ollama Public Key?
An API key authenticates a program that calls https://ollama.com/api directly. Create and manage API keys in Ollama settings. See Creating an API key for an example.
Your Ollama Public Key identifies a local Ollama installation to ollama.com. It is used when you sign in locally to run cloud models, push models, or pull private models.
Where can I find my Ollama Public Key?
The Ollama Public Key is the public part of the key pair that lets your local Ollama instance communicate with ollama.com.
You need it to:
Push models to Ollama
Pull private models to your machine
Run models hosted in Ollama’s cloud through your local Ollama installation
Add the key to your account
Sign in from the Settings page in the macOS or Windows app, or sign in from the CLI:
ollama signin
You can also copy and paste the public key on the Ollama Keys page.
Find the key on disk
Operating system Path to id_ed25519.pub
macOS ~/.ollama/id_ed25519.pub
Linux /usr/share/ollama/.ollama/id_ed25519.pub
Windows C:\Users\<username>\.ollama\id_ed25519.pub
Replace <username> with your Windows user name.
