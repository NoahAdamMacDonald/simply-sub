Using Bridge
It is essential that you keep your software up-to-date. The latest version of an app introduces new features and fixes any bugs or vulnerabilities that were recently discovered, improving its security, reliability, and overall user experience.
It’s no different with Proton Mail Bridge. Our development team releases new versions of Bridge regularly and wants to make the update process as smooth as possible.
Depending on your preference, you can update Bridge in two ways.
Automatic Update
Automatic Update is the easiest way to ensure you don’t miss any new versions. Automatic Update is on by default in Bridge (you can confirm this by checking the Keep the application up to date option under Settings), so you will not need to do much. The app will automatically detect and download any updates in the background. All you will need to do is restart Bridge once it shows you a notification that the new update is ready.
Manual update
Although we recommend using the Automatic Update feature, some users might prefer to handle updating Bridge manually. It’s still a simple process:
Disable the Keep the application up to date option in Settings.
After you have selected this option, Bridge will let you know a new update is available, but the app won’t download or install it for you. You will need to download updates yourself following the in-app instructions.
To check if you are using the latest version, simply click on Check for updates in the Help tab.
