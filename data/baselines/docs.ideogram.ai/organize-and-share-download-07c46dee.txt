Use Ideogram's Download button rather than your browser's "Save image". The button lets you pick the file type and size, save a transparent PNG, or upscale an image as you download it.
Download one image
Open the image
Open the image to see its asset page.
Click Download
Click Download in the action bar.
Click Download at the top right.
Pick a file type
Pick a File type: JPEG, PNG or WEBP.
Choose the file type.
Pick a size
Pick a Size: 1K, 2K, 4K or 8K. Each size shows its pixel dimensions and a tag:
(Original size): the image as it was made.
(Upscale): Ideogram upscales the image first, then downloads it.
Each size shows its pixel dimensions and a tag.
Download
Click the button at the bottom of the menu.
The menu lists the original size, any smaller sizes, and upscale sizes up to the largest that fits. A 2K image, for example, offers 1K, 2K (Original size), 4K and 8K. The button text changes with your choice:
Button When
Download You picked the original size or a smaller one.
Upscale & download You picked an upscale size. This spends credits, and the button shows how many. See how credits work.
Subscribe to download Your choice needs a paid plan.
To control the upscaler yourself, use the Upscale app instead. It works without a plan if you've bought credits, while Upscale & download needs a paid plan. See Upscale.

Options you can't use show a crown icon. Click one to see plans. See Plans and Credits.
Transparent images
Images with a removed or transparent background are different. Anyone can download them as PNG at 1K, free. JPEG is turned off for them, because JPEG can't keep transparency. See Transparent Backgrounds and Remove Backgrounds and Objects.
Quick download from the grid
Tiles in Library show a Download icon, and the right-click menu has Download image. Both skip the menu. With a paid plan, the default is PNG at original size. Without one, the default is JPEG at original size, or a 1K PNG for a transparent result. Open the asset page's Download menu when you want to choose a different format or size.
Download many at once
Open Library
Open Library → Generations or Uploads, or open a collection.
Select items
Select the items you want. See Library and Favorites.
Click Download in the bar
Click Download in the bar at the bottom.
Click Download in the bar.
Ideogram builds a ZIP file named ideogram-images-<date>.zip. Images come as PNG if you subscribe and JPEG if you don't.
The ZIP also holds a CSV file with one row per item. It lists the file name, prompt, Magic Prompt text, aspect ratio, model, visibility, seed, style, color palette and a link to the asset.
Bulk downloads have these limits:
Library selections are limited to 250 items. Subscribed collection views can support larger direct selections; collection results that include sub-collections through attribute filters keep the 250-item limit. The selection bar shows when you reach the limit.
A Library bulk download can include up to 50 videos. Select fewer videos if you reach that limit.
If you see You already have bulk downloads in progress…, wait for one to finish before starting another.
To download a whole collection, open its … menu and click Download.
While a ZIP is being prepared
A bulk or collection download needs time to build the ZIP. Preparing… and the download-progress indicator mean that preparation is still running; the file downloads when it is ready. You can move around the app while it is being prepared.
If you see Download failed or Download timed out, try the download again. If the app asks you to wait before downloading the collection again, let that wait finish rather than repeatedly starting new attempts.
Downloads in the iOS app
Bulk image downloads in the iOS app save images to your photo album. Videos cannot be saved in bulk there: open each video and use its own Download button. The iOS app doesn't support collection downloads; use the web app for a collection ZIP.
Videos
Videos download as one MP4 file, named after the asset. There's no format or size choice. If a video is still being made, you'll see "Video is not available for download yet."
SVG assets
If an available app has already produced an SVG asset, Download saves that original .svg file directly. It does not use the JPEG/PNG/WEBP format and size menu described above.
Choosing PNG, JPEG or WEBP for a regular generated image does not turn it into vector artwork. Those formats remain pixel images. SVG assets also do not support image-only actions such as Remix, Upscale or Remove BG; those actions require a regular image source.
