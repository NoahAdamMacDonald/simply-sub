Trend Micro VPN v6.x Data Collection Notice
Views:
Default Collection
Trend Micro VPN automatically collects and transmits the following data, some of which may be considered personal data in certain jurisdictions, after installing/enabling the product. It is necessary to collect this data to provide the security functions on this product. Therefore, you cannot disable these features. If you do not want Trend Micro to access this data, you should uninstall and stop using the product.
License Check
DESCRIPTION
To check that the license is updated.
DATA COLLECTED
Email account
Password
First Name
Last Name
Language
Phone Number (Japan only)
IAP information
IAP token
Purchase time
Activation Key
FEATURE LOCATION
This feature cannot be disabled.

Trend Micro VPN also uses this data to improve product stability, usability, and performance.
