Credit update & usage rules
All Kimi membership features (Agent, Deep Research, Slides, Docs, Sheets, Kimi Code, Kimi Work, Kimi Claw, etc.) share a single credit pool. Credits are consumed based on actual usage.
How does the shared credit pool work?
Kimi membership features share a single credit pool that works everywhere. Agent features and other Kimi features all draw from it:
Feature Description
Agent tasks Build, documents, slides, spreadsheets, deep research
Kimi Code AI-powered coding assistant for developers
Kimi Work Kimi desktop app
Kimi Claw Your personal cloud-deployed AI assistant
Other features Image generation and more
K2.6: In Chat, K2.6 also consumes membership credits, billed the same way as when it is used as a K2.6 Agent inside Kimi Work.
Kimi Code: New plans with Kimi Code access (Plus and higher) have a rolling 5-hour usage limit and no weekly limit. Legacy plans retain both rolling 5-hour and weekly limits. These are usage limits, not a cap of five hours of use per week, and apply only to Kimi Code. Exhausting the monthly shared credit pool also affects Kimi Code.
This means you can allocate credits however you like across the shared pool — spend more on research one month, more on documents the next.
How are credits calculated?
Credits are consumed based on the number of tokens a task processes. Longer inputs and outputs use more tokens.
Usage varies with the model, context length, tool calls, and plan. Check your usage details for actual consumption.
Credit refresh rules
Rule Description
Cycle Monthly and annual subscribers both receive credits on a monthly cycle
Expiration Unused credits expire at the end of each cycle — they do not roll over or convert to cash
Kimi Code usage limits Separate from the monthly credit pool; see below. These do not describe task concurrency
Kimi Code limits for new and legacy plans
Rule New plans (Plus and higher) Legacy international plans (Moderato and higher)
Rolling 5-hour usage limit Yes Yes
Weekly limit No Yes; resets every 7 days from the subscription start time
Monthly shared credit pool Applies Applies
A rolling 5-hour limit caps usage within that window; it does not mean you can use Kimi Code for only five hours per week. Check the Kimi Code console for your remaining usage, reset times, and applicable rules. See the official membership guide for details.
When credits run out
Any task already in progress will finish normally
New tasks will show an "insufficient credits" prompt
Your options:
Wait for your credits to refresh at the next billing cycle
Upgrade to a higher-tier plan for a larger monthly allowance
How exactly do credits refresh?
Cycle-based — Credits refresh on your subscription anniversary date, not the calendar month
No rollover — Remaining credits reset to zero, then your full allotment is re-issued
Example — If you subscribed on December 1 at 3:00 PM, your credits refresh on January 1 at 3:00 PM
System errors: If a task fails due to a system issue, use the 👎 button to report it and request a credit refund.
