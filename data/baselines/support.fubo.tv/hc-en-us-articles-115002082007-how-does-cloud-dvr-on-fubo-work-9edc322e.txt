How does Cloud DVR on Fubo work?
February 28, 2025 17:58
Updated
Overview
Fubo's Cloud DVR allows you to record live programs and access them across your supported devices. All US plans include unlimited Cloud DVR storage at no extra charge.
Frequently Asked Questions About Cloud DVR
What can I record?
Record live programs on most channels
Schedule recordings either before or during the live program
Record as many simultaneous programs as you’d like
How do I schedule a recording?
Select the Record icon from your channel guide or the info page of a selected program
See also: How can I record a program?
How do I watch my Cloud DVR recordings?
Go to the My Stuff section to view and manage your recordings, check scheduled recordings, or resume to resume watching something you previously started
Recordings are available for playback from the beginning as soon as the recording starts
See also: What is My Stuff?
How long can I save my recordings?
Recorded programming will remain on your Cloud DVR for 9 months unless you choose to delete it before that
Recordings that remain on your Cloud DVR for 9 months will automatically expire and be deleted at that time
How do profiles work with Cloud DVR?
Each user profile can access the recordings scheduled under that profile
To view a specific recording, switch to the profile that initiated the recording
See also: How do Profiles work on Fubo?
Additional Questions About Cloud DVR
Are there any restrictions to using Cloud DVR?
Device Restrictions: If the original broadcast was subject to any device restrictions, those restrictions will exist for the recording
Ex: If a program doesn’t allow viewing on mobile devices, you will not be able to view a Cloud DVR recording of the program on a mobile device
Supported Channels and Programs: While most content allows for recording with Cloud DVR, if a record option is not available, the channel or program does not allow recording with Cloud DVR
Can I record multiple programs at the same time?
Yes, you can record multiple programs simultaneously with unlimited Cloud DVR space
How do I delete a recording?
Delete recordings from your My Stuff page
See also: How do I delete recordings from Cloud DVR?
