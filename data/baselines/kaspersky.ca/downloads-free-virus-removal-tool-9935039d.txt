Frequently Asked Questions
How do you remove a virus from an already infected computer?
Removing an active infection needs a scan that targets what is already on the machine rather than only guarding against new threats. The Kaspersky Virus Removal Tool is a free, on-demand utility that scans an infected computer and removes viruses, adware, riskware, Trojans and rootkits it finds. You download it, run a scan, and it cleans what it detects, which makes it suited to a machine that is already compromised rather than one you are protecting in advance.
What is a free on-demand virus scanner and when should you use one?
An on-demand scanner runs only when you start it, checking a computer for infection at that moment rather than protecting it continuously. The Kaspersky Virus Removal Tool is this kind of free scanner, best used when you suspect a device is already infected or want a second opinion alongside your existing security. It is not a replacement for always-on antivirus, since it does not run in the background, but it is a fast way to check and clean a machine on the spot.

How do you remove malware that blocks your antivirus from running?
Some malware actively runs and tries to stop standard antivirus software from opening or working. The Kaspersky Virus Removal Tool uses advanced disinfection technology built to fight active infections of this kind, targeting malware that is running and resisting removal. Because it is a separate on-demand tool you download and run, it can get onto a compromised machine and clean it even when the installed security has been disabled.

What parts of a computer can a virus removal tool scan?
A thorough scan can target the places malware hides rather than only obvious files. The Kaspersky Virus Removal Tool lets you choose the scan areas, including startup objects, boot sectors, system memory and hard drive volumes, so you can check the parts of the system where infections take hold. Narrowing or widening the scan this way helps you run a quick targeted check or a deeper sweep depending on what you suspect.
