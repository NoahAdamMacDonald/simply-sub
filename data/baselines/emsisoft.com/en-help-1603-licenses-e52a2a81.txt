Getting Started
Licenses
January 4, 2019
1 min read
When installing Emsisoft Anti-Malware, you have a few options to choose from:
Test for 30 days, free – If you want to test the program more thoroughly then select this option. If you have already used your trial period, you will be asked if you wish to use the scanner-only freeware mode.
Enter license key – If you already have a valid license then enter the key you received with your order (sent to the email address you provided when purchasing) and confirm the information by clicking the Next button. If you have a license key with multiple seats, the program will automatically map a free seat with this computer. The license key can't be used on more personal computers or servers than it is licensed for. Note that you can easily transfer a license to a new computer at any time, however there is a limit of 3 hardware changes per 24 hours.
Order now – If you haven't yet purchased a license key and wish to do so now, then select this option to be taken to the Emsisoft online store.
If your Internet connection uses a Proxy Server then you can configure the corresponding settings such as server address and user information in the dialog displayed when you click the Proxy settings button.
