How do I keep Windscribe up to date?
What is it?
We release new versions of our apps quite often, and the desktop applications have 3 Update Channels.
Release
Latest stable versions of Windscribe. Released least often.
Beta
Pre-release builds of new versions of Windscribe. Released more often.
Guinea Pig
Sneak preview of new features and bug fixes. Can be unstable.
Get Windscribe Now
Why should i care?
If you report a bug, or a feature, it will be released in the Guinea Pig channel first. You can test the fixes and new features ahead of a wide release and provide feedback. If you wish to encounter as few bugs as possible, stick to the Release channel.
